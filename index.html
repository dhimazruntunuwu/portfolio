Tentang

Cara saya bekerja

Saya Kirana, seorang programmer yang fokus membangun produk di dua dunia: web modern dan Android native. Saya suka mengubah ide yang masih mentah menjadi aplikasi yang terasa ringan, jelas alurnya, dan mudah dirawat jangka panjang.

Di sisi web, saya terbiasa menangani antarmuka interaktif hingga REST/GraphQL API dan basis data. Di sisi Android, saya membangun aplikasi dengan Kotlin dan Jetpack Compose yang responsif, hemat baterai, dan tetap andal meski kondisi jaringan kurang stabil.

"Kode yang baik bukan cuma jalan hari ini—tapi cepat dipahami, aman diskalakan, dan enak dipakai pengguna."

  1. 2022 Memulai perjalanan pemrograman lewat HTML, CSS, JavaScript, dan membuat situs interaktif pertama.
  2. 2023 Mendalami React, Next.js, Node.js, dan database relasional untuk membangun aplikasi web full-stack.
  3. 2024 Berekspansi ke pengembangan Android menggunakan Kotlin, Jetpack Compose, dan arsitektur MVVM/Clean.
  4. 2025–26 Menangani proyek end-to-end lintas web & Android untuk produk bisnis, otomasi, dan aplikasi utilitas.
