# Kirana — Web & Android Programmer Portfolio

Portofolio interaktif bergaya *multiplayer canvas* di mana **18 kursor agen** menyusun halaman secara bertahap (108 layer), dilengkapi kontrol pemutaran dan *cursor swarm* interaktif di bagian kontak.

## File Utama
- `index.html` — Struktur halaman & elemen portofolio
- `styles.css` — Tema gelap, tipografi, *wireframe* seleksi, dan tata letak responsif
- `app.js` — Mesin animasi 18 agen, efek ketik, audio Web Audio API, dan *name cursor swarm*

## Menjalankan Secara Lokal
Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
npx serve .
```
